# Rokibul Hassan — Personal Profile Website

Responsive portfolio based on the uploaded CV.

## Files
- `index.html` — content and page structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and current footer year

## Run locally
Extract the ZIP and open `index.html` in a browser. Internet access is used for Google Fonts and Tailwind CSS CDN.

## Publish
Upload these files to GitHub Pages, Netlify or Cloudflare Pages. Keep all three files in the same folder.

## Privacy
The public page omits date of birth and full street address. It includes the CV email and phone number as contact methods; review before publishing. CV award date is reproduced as 26 June 2026.


## Profile photo
`rokibul-hassan-profile.jpg` is the portrait displayed in the hero section. Keep this image in the same folder as `index.html`, `style.css` and `script.js`.
